오디오와 영상, 각각의 전문 모델로
합성 여부를 교차 검증합니다

영상을 업로드하면 오디오 트랙과 이미지 프레임을 분리한 뒤, 각각 독립적으로 학습된 딥페이크 탐지 모델의 추론을 거쳐 최종 판정을 내려드립니다.

영상 업로드하고 분석 시작 동작 방식 보기

분석은 이렇게 진행돼요

업로드부터 결과 대시보드까지, 4단계 파이프라인으로 동작합니다.

1

영상 업로드

분석하고 싶은 영상 파일을 웹페이지에 업로드합니다.

2

오디오 / 이미지 분리

업로드된 영상을 오디오 트랙과 이미지(프레임) 데이터로 나눕니다.

3

개별 모델 추론

오디오 딥페이크 탐지 모델과 이미지 딥페이크 탐지 모델이 각각 독립적으로 추론합니다.

4

결과 종합

두 모델의 결과를 종합해 최종 판정과 상세 대시보드를 보여줍니다.

왜 오디오 / 이미지 모델을 분리했나요?

합성 영상은 이미지와 음성 중 한쪽에서만 흔적이 남는 경우가 많습니다. 각 도메인에 특화된 모델을 따로 두면 놓치는 신호를 줄일 수 있습니다.
